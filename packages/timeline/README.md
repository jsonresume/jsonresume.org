# @repo/timeline

`/@username/timeline`: a resume as a career at a glance. `toTimeline(resume)`
puts every dated thing (jobs, volunteering, schools, projects, awards,
certificates, publications) in order, newest first with current roles on
top; `TimelinePage` (`@repo/timeline/ui`) shows it with how long each lasted
and a few totals. The registry had a timeline page; this one is server
rendered from the same resume `/@username` shows.
