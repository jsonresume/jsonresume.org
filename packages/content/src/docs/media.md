## The short version

JSON Resume is a community-developed, open-source schema for expressing a résumé as JSON. Started in 2014 by Thomas Davis and Roland Sharp, it separates career information from presentation so compatible tools can use the same data to build documents and portfolio websites.

The schema, command-line tools and hosted registry are distinct parts of the project. You can use the format without publishing personal information to the registry. See the [schema](/schema), [getting started guide](/getting-started) and [live registry](https://registry.jsonresume.org/explore).

A common file format does not guarantee acceptance by an employer or applicant tracking system. Output and supported fields depend on the tool and theme you choose.

### Outside implementations

These projects document their use of the format. They are maintained independently; their inclusion here does not imply an endorsement.

- [TechFolios, University of Hawaiʻi](https://techfolios.github.io/): a technical-portfolio system that uses JSON Resume for biographical information.
- [The jsonresume package on CTAN](https://ctan.org/pkg/jsonresume): Lukas Wolfsteiner's LuaLaTeX package renders JSON Resume data into documents.

For dated milestones and original announcements, see the [project history](/team#history). For how the schema evolves, see the [schema roadmap discussion](https://github.com/jsonresume/jsonresume.org/issues/329).
