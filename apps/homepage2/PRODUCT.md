# Homepage context

## Register

brand

## Users and purpose

The public JSON Resume marketing site introduces the schema, tools and themes
to developers and job seekers. The media page helps reporters verify facts,
find original records, try an example and contact a co-founder.

## Voice and design principles

Preserve the existing straightforward, practical, developer-oriented identity:
Open Sans, white content surfaces, yellow navigation and red accents. Prefer
working examples and source links to promotional claims. Distinguish the
community format from hosted services and third-party implementations.

## Anti-references

Avoid unsupported popularity claims, speculative feature lists, decorative
dashboard metrics and a visual redesign unrelated to these content changes.

## Accessibility and inclusion

Follow the repository's WCAG 2.2 AA target. Use semantic headings, descriptive
links, visible keyboard focus, readable contrast and responsive content.
