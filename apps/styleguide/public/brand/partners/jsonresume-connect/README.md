# JSON Resume Connect icon

A variant of the JSON Resume mark made for
[JSON Resume Connect](https://github.com/ismailkattakath/jsonresume-connect),
an independent Google Workspace app built on Sign in with JSON Resume
(see
[#638](https://github.com/jsonresume/jsonresume.org/issues/638)). The mark, filled with the brand yellow, sits in front of the
document it becomes.

JSON Resume Connect may use these files as its app icon, OAuth consent
logo and listing images. Describe it as an independent app that works with
JSON Resume; the plain JSON Resume logo stays the project's own.

| File | Size |
|---|---|
| `icon.svg` | vector (128 viewBox), source of the PNGs |
| `icon-32.png`, `icon-128.png` | Marketplace app icon |
| `icon-48.png`, `icon-96.png` | web-app integration sizes |
| `icon-120.png` | OAuth consent screen logo |
| `icon-512.png` | README header, social preview |

All are square with a transparent background.
