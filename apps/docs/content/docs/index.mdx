JSON Resume is a community standard for resumes: one `resume.json` file that
tools, themes and services can all read.

## Guides

- [Getting started](/guides/getting-started): write a `resume.json`, validate it and render it
- [Schema](/guides/schema): every section and field, and how to validate in code
- [Registry](/guides/registry): host your resume at `registry.jsonresume.org/<username>` from a GitHub gist
- [CLI](/guides/cli): render HTML, PDF, Markdown and text locally with `resume-cli`
- [Themes](/guides/themes): use a theme, or build and publish your own

## Internals

The pages under **Internals** describe how the jsonresume.org monorepo is put
together (registry app, job search, ATS scoring and so on). They are written
for contributors. See also
[CONTRIBUTING.md](https://github.com/jsonresume/jsonresume.org/blob/master/CONTRIBUTING.md).
